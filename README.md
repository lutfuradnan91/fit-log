Project name : FitLog — Workout Planner 🏋️

Short description based on my project : FitLog is a workout planning web application built with Next.js. It helps users explore exercises, view workout details,create a daily workout plan, save workouts for later, and track completed exercises.

Technologies used :

Next.js — React framework
React — User interface development
JavaScript — Application logic
Tailwind CSS — Styling and responsive design
DaisyUI — UI components
React Toastify — Toast notifications
LocalStorage — Persistent workout data
REST API — Workout data fetching

5 key features of the project:

1)  Workout Library

Browse available workouts with images, names, muscle groups, equipment, duration, calories, and ratings.

2) Workout Details

View detailed workout information, including difficulty, equipment, sets, repititions, and exercise instructions.

3) My Plan

Add workouts to a personal daily plan and manage up to five planned workouts.

4) Saved Workouts

Save workouts for later and manage your saved exercise list separately.

5) Workout Progress Tracking

Mark planned workouts as completed, remove workouts, and receive toast notifications. Workout data persists in LocalStorage, even after refreshing the page.
